# Open-Source Release Checklist

- [ ] Add the final implementation code.
- [ ] Add installation and environment instructions.
- [ ] Add dataset download and preprocessing instructions.
- [ ] Add training and evaluation commands.
- [ ] Add released checkpoint links and checksums.
- [ ] Add simulation and real-world evaluation notes.
- [ ] Add project figures or a project-page link.
- [ ] Choose and add an open-source license.
- [ ] Verify that no private data, credentials, or unpublished files are included.
- [ ] Replace the provisional citation with the final bibliographic entry after publication.
